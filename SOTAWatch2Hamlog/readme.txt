SOTAWatch to HAMLOG 導入・操作ガイド V1.6
==========================================

このツールは、SOTAwatch3のLog ChaseウインドウからTurbo HAMLOGの入力ウインドウへ
日付、時刻、周波数、モード、コールサイン、サミット情報、および入力したRSTレポートを
一括転送するためのツールです。

[1] インストール方法

A. Pythonのインストール
Pythonがインストールされていない場合は、公式サイトからインストールしてください。
インストールされているかどうかは以下の方法で確認してください。
Windowsキー+Rで「ファイル名を指定して実行」を開き、cmdと入力してコマンドプロンプトを起動します。
コマンドプロンプトで以下のとおり実行してください。バージョンが表示されればインストールされています。
python --version

B. Pythonライブラリの導入
Windowsキー+Rで「ファイル名を指定して実行」を開き、cmdと入力してコマンドプロンプトを起動します。
コマンドプロンプトで以下のとおり実行してください。
pip install flask flask-cors pywin32

C. ファイルの展開
sotawatch2hamlog.zipを任意のフォルダに展開してください。
すべて同じフォルダに展開してください。

D. SOTA日本山名リストの登録（オプション）
HAMLOGの入力ウインドウに転送するサミット情報として、SOTA IDに加えて山名を追加したい場合は、
JA1CTC局のホームページから国土地理院地図用GeoJSON形式のSOTA日本山名リスト（例：geojson_v31.zip）を
ダウンロードして、ZIPファイルのまま上記フォルダのgeojsonサブフォルダに置いてください。

E. スタートアップへの登録
Windowsキー+Rで「ファイル名を指定して実行」を開き、shell:startupと入力してOKボタンを押すと
スタートアップフォルダが開きます。sotawatch2hamlog.zipを展開したフォルダにある
start_hamlog_bridge.vbsのショートカットを作成して、ショートカットをスタートアップフォルダに移動します。
その後、一度、サインアウトし、サインインしなおしてください。

F. ブラウザ拡張機能（Chrome等）の登録
ブラウザ（ChromeまたはEdge）で chrome://extensions を開きます。
デベロッパーモード（または開発者モード）をONにします。
Chromeの場合は「パッケージ化されていない拡張機能を読み込む」、Edgeの場合は「展開して読み込み」を
クリックし、sotawatch2hamlog.zipを展開したフォルダを選択します。

[2] 初期設定（重要）
ブラウザのツールバーにある拡張機能アイコン（パズルピース）から「SOTAWatch to HAMLOG」を選び
ピン留めします。
拡張機能アイコンの左に「SOTAWatch to HAMLOG」のアイコンが表示されるので左クリックすると
メニューが表示されます。
以下の項目を設定し「設定を保存」をクリックしてください（変更がない場合も保存してください）。

転送先ウインドウ: 
  転送する入力ウインドウ（LOG-[A] または LOG-[B]）を選択します。

転送先フィールド: 
  サミット情報をRemarks1とRemarks2のどちらに追記するか選択します。

サミット書式: 
  Remarksに転送するサミット情報の書式を設定します。
  {summit_id}がSOTA IDに、{summit_name}が山名に置換されて転送されます（ただし、山名は日本の山のみ）。
  初期設定は"{summit_id} {summit_name}"です。これはSOTA IDと山名、つまり「JA/TK-001 雲取山」を
  転送します。
  たとえば書式を"$S={summit_id}$"とすると$S=JA/TK-001$が転送されます。
  Remarksに文字が入力されている場合はその後ろに追記します。

時刻表示:
  JST または UTC を選択。

設定後はSOTAwatch3のページをいちどリロード（F5またはCtrl+F5）してください。

[3] 使用方法
Turbo HAMLOGを起動し、入力画面（LOG-[A]またはLOG-[B]）を開いておきます。
SOTAwatch3にログインし、交信した局のLog Chaseウインドウを開きます。
「Submit」ボタンの下に表示される「HAMLOG転送」ボタンをクリックします。
「LOG-[A]へ転送しました」というメッセージが出れば転送成功です。
Log ChaseウインドウのHis欄, My欄に交信で交換したRSTを入力しておくと、それらも転送されます。

「Submit」ボタンを押すとLog Chaseウインドウが閉じてしまうので、
必ず「HAMLOG転送」ボタンを先に押してください。

SOTAwatch3のスポット表示数の設定を多くすると（「最新一週間のスポット」など）、
Log Chaseウインドウの動作が非常に遅くなるので、スポット表示数は少な目に設定してください。

Log Chaseウインドウの時刻の右の更新ボタンを押すと現在時刻に更新されます。
「HAMLOG転送」ボタンを押す前に時刻を更新してください。

[4] その他
geojsonフォルダのSOTA日本山名リストを更新した場合は、一度、サインアウトし、サインインしてください。
